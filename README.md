# Act-1---U1---Herramientas-comp.
Repositorio usado en la Act 1 - U1 - del curso de Herramientas Computacionales para documentar los cambios.

# Organización
Se crearon 4 carpetas para mantener el orden de la mejor manera posible:

- Datos originales: Se encuentran los datos originales sin editar para evitar alteraciones accidentales y obtener resultados erroneos.
- Procesamiento: Se encuentra el archivo de entrada modificado con el supuesto de sus medidas.
- Documentación: Se encuentra la bitácora y el checklist de la actividad.
- Resultados: Se encuentra el Grafico final del ensayo de compresión 

# Proposito
Se busca reorganizar la información entregada para que sea de comprensión rápida y que cualquier otra persona pueda replicarlo.

- Entrada: La entrada será el archivo "ensayo_hormigon_FINAL_v2.xlsx" que posee los datos para realizar el grafico.
- Procedimiento: El archivo "ensayo_hormigon_FINAL_v2.xlsx" fue procesado y gracias a la formula en la fila del calculo de esfuerzo fue posible verificar las unidades de los datos, se determinó que las medidas D y H corresponden a medidas de una probeta cilíndrica de "150 x 300 mm" la carga (P) se encuentra en Kn, el desplazamiento (u) en mm y el esfuerzo (sigma) en MPa.
- Salida: Se tiene el grafico final del ensayo de compresión y el informe del mismo.
- Herramientas utilizadas: Excel, Github
- Unidades/Supuestos: Se hizo el supuesto de que las medidas D y H estaban en milímetros. El grafico no presenta unidades.
